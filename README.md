# Hayali Asansör Butonu Protokolü

> **Resmi uyarı:** Bu depo, var olmayan katlara basma hakkını insanlığa kazandırmak üzere kurulmuştur.  
> Fiziksel asansörlerle karıştırılması halinde sorumluluk kullanıcının hayal gücündedir.

## Bu nedir?

Dünyanın ilk **çalışan ama hiçbir yere gitmeyen** asansör yazılımı.  
Butona basarsınız. Program ciddiyetle düşünür. Bina kıpırdamaz.  
Bilim bunu "başarı" olarak tanımlar.

## Kurulum (3 saniye, 0 mühendis)

```bash
python3 asansor.py
python3 asansor.py π
python3 asansor.py 404
```

Python 3 yeter. Bağımlılık yok. Asansör de yok.

## Desteklenen hayali katlar

| Kat | Anlamı |
| --- | --- |
| `0` | Zemin. Ayakkabı bağcığı çözük bekleyenler. |
| `-1` | Bodrum. Kayıp çorap sendikası. Patates yasaktır. |
| `∞` | Sonsuz kat. Çay demlenirken geçen ömür. |
| `π` | Pi katı. Dairesel karar. İnilemez. |
| `404` | Evrak var, imza yok. |
| `öğle` | Öğle uykusu. Kapı kapanır, kimse sormaz. |
| `meclis` | Kedi Meclisi. Tüy ile çoğunluk. |
